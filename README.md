## Development

Use Node.js 24 or later and pnpm 12 or later.

```bash
pnpm install
pnpm develop
```

Check lint errors:

```bash
pnpm lint
```

Build source locally:

```bash
pnpm build:dry-run
```

## Deployment

Build source with Algolia:

```bash
pnpm build
```
